# ⚡️ Nick Checker — проверка юзернеймов Telegram

Реально работающий сервис проверки занятости юзернеймов. Каждый результат —
реальный запрос к Telegram (MTProto): `contacts.ResolveUsername` + `account.CheckUsername`.
Никаких имитаций, случайных ответов и демо-данных.

## Статусы

| Статус | Значение |
|---|---|
| 🟢 **FREE** | Ник свободен, можно установить прямо сейчас |
| 🔴 **TAKEN** | Занят: показывается тип владельца (пользователь / бот / канал / группа) и имя |
| 🟡 **UNAVAILABLE** | Никем не отображается, но Telegram не даёт его занять (зарезервирован и т.п.) |
| ⚪ **ERROR** | Не удалось проверить — причина показывается как есть |

## Режим 1. Бот + мини-апп (GitHub, $0)

Бот живёт на GitHub Actions (keep-alive), мини-апп — на GitHub Pages.
Всё бесплатно. Отправьте боту:

- `@durov` или просто `durov` — мгновенная проверка одного ника
- список: `nick1, nick2, nick3` — очередь с живым прогрессом
- шаблон: `ka??a` ( `?` буква, `#` цифра, `*` любая )
- генератор: `/gen 8 произносимые 50`
- `⭐ Избранное` — ники «хочу занять», повторная проверка одним нажатием
- кнопка 🚀 Приложение — мини-апп (проверка, история, избранное, инфо)

Прогресс одной очереди редактируется одним сообщением: счётчики, ETA,
FloodWait с обратным отсчётом. При FloodWait > 15 минут очередь честно останавливается.

## Режим 2. Локальный сервис (свой компьютер / сервер)

1. Получите `api_id` и `api_hash`: [my.telegram.org](https://my.telegram.org) → API development tools.
2. Скопируйте `.env.example` → `.env`, заполните `API_ID`, `API_HASH`, `ACCESS_PASSWORD`.
3. Разовый вход: `python login.py` (телефон → код → 2FA). Сессия — в `data/`, строка SESSION печатается для GitHub Secrets.
4. Запуск: `run.sh` (Linux/macOS) или `run.bat` (Windows).
5. Откройте с телефона в той же Wi-Fi сети: адрес печатается при старте, вход по паролю.

Рекомендация: используйте **отдельный аккаунт-проверяльщик**.

## Честные ограничения

- Telegram ограничивает частоту: одна проверка за раз, пауза 1.5 с (настраивается).
- Ники короче 5 символов Telegram не поддерживает.
- Свободный ник могут занять другие до того, как вы его установите.
- Сервис не показывает приватные данные владельца ника (телефон и т.п.).

## Установка найденного ника

Telegram → **Настройки → Изменить профиль → Имя пользователя**.

## Тесты

```bash
python3 -m pytest tests/ -q          # 25 юнит- и ботовых тестов
```

Ручной чек-лист: `durov` → TAKEN, `ab` → понятная ошибка, случайный длинный ник → FREE/UNAVAILABLE.

## Структура

```
app/
  main.py       # FastAPI + SSE (локальный режим)
  checker.py    # Telethon: ResolveUsername + CheckUsername
  queue.py      # очередь, пауза, FloodWait, повторы
  generators.py # список / шаблон / генератор / словарь
  db.py         # SQLite: история, кэш 10 мин, избранное
  auth.py       # пароль + cookie (локальный режим)
  botmode.py    # бот (Actions) + выгрузка данных для мини-аппа
  sync.py       # ветка data: бэкап БД + JSON для Pages
docs/         # мини-апп — один UI для обоих режимов (GitHub Pages и локальный сервер)
login.py        # разовый вход
run.sh / run.bat
```
