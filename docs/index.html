Как это работает

Каждый результат — реальный запрос к Telegram (MTProto): сначала проверяется, занят ли ник, затем — можно ли его установить. Никаких имитаций и «случайных» ответов.

Статусы

  • 🟢 Свободен — ник можно установить прямо сейчас
  • 🔴 Занят — принадлежит пользователю, боту, каналу или группе
  • 🟡 Недоступен — никто не отобразил, но Telegram не позволяет занять
  • ⚪ Ошибка — не удалось проверить, причина показывается как есть

Правила ников

  • Только латиница a–z, цифры и «_», длина 5–32
  • Начинается с буквы, не заканчивается на «_», без «__»

Честные ограничения

  • Telegram ограничивает частоту запросов: очередь идёт по одному, с паузой (по умолчанию 1,5 сек)
  • При FloodWait вся очередь встаёт на паузу и продолжается сама
  • Свободный ник могут занять другие до того, как вы его поставите
  • Рекомендуется использовать отдельный аккаунт-проверяльщик

Как установить ник

Telegram → Настройки → Изменить профиль → Имя пользователя.
